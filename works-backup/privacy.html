Privacy policy

works backup · effective 8 November 2026

works backup is a personal tool. It is run only by its author, the site owner, on their own computer, to back up their own files to their own Google Drive.

Data it accesses

With the Google permission drive.file, the tool can access only the files and folders it has created in the signed-in user's Google Drive. It uses that access to create folders, upload files, and read back each uploaded file's id and checksum. It does not read, change or delete any other file in Google Drive, and it does not access any other Google data.

Where data goes

Files go directly from the user's computer to the user's own Google Drive over Google's API. No data is sent to the author, to any server of the tool, or to any third party. The tool has no server, no analytics and no advertising.

What is stored locally

The sign-in token issued by Google is stored on the user's own computer, readable only by that user's account. A record of uploaded files (path, Drive file id, checksum) is kept in the user's own library folder.

Revoking access

Access can be withdrawn at any time in the Google account under Security → Third-party apps & services. Files already uploaded stay in the user's Google Drive until the user removes them.

Google API Services User Data Policy

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
