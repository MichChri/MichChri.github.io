works backup

A personal command-line tool that copies the site owner's works library to their own Google Drive.

What it does

The works library is a local archive of songs, recordings, lyrics, videos and project material. works backup uploads that archive, one way, into a single folder in the owner's Google Drive, mirroring the folder layout of the library.

  • It only adds files. It never deletes or overwrites anything in Google Drive.
  • It checks every upload against the checksum Google Drive reports, without downloading the file again.
  • It keeps a local record of what was uploaded: path, Drive file id and checksum.

Who uses it

Only its author. It is not a public service, it is not offered to other users, and it has no accounts of its own: it runs on the author's computer and signs in to the author's own Google account.

Google access

It asks Google for one permission, drive.file: access to the files this tool itself creates in Google Drive, and to no other files. It cannot see or read anything else in the Drive.
